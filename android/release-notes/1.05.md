**Driver workarounds for Turnip.** 1.04 (no tiled drawing) did not cure the stripes with a Turnip driver: the black columns changed shape, from 96 pixels apart to 16 of every 48, which shows Turnip's way of drawing is to blame, but not which part of it. Settings > GPU driver now has **Driver workarounds** while a custom driver is installed:

- **Safest** (the default): turns off tiled drawing, colour compression, the coarse depth test and the driver's cache shortcuts. The slowest, and the most likely to give a clean picture.
- **Both**, **No UBWC**, **No tiling**: lighter, faster sets.
- **Driver's own**: Turnip as it comes.

Each takes effect the next time the game starts. If Safest gives a clean picture, try the lighter ones to find the fastest that stays clean, and please report which one it was (with your phone and driver), so it can become the default.

Nothing changes with the phone's own driver.
