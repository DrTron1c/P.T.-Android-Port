**Fix for custom GPU drivers.** With a Turnip driver installed (Settings > GPU driver), the picture could flicker between black, red stripes and blocks over the scene and the touch buttons, with a correct frame only now and then: frames were reaching the screen before the GPU had finished drawing them. With a custom driver the game now finishes each frame before it is shown. This costs a little speed with a custom driver only; nothing changes with the phone's own driver.

If the picture is still wrong with your driver, please open an issue with your phone, the driver's name and Log > Share, or go back to the phone's driver (Settings > GPU driver > Use the phone's driver).
