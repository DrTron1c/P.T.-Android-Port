**Custom GPU driver (Adreno phones and tablets).** Settings in the main menu now has a **GPU driver** section: install a Vulkan driver from a .zip (for example a Turnip build, as emulators such as Winlator and PPSSPP use) or go back to the phone's own driver. It takes effect the next time the game starts. If the driver cannot start the renderer, the game falls back to the phone's driver by itself, so it cannot trap you in a crash loop. Nothing changes unless you install a driver; on other GPUs the section is not shown. Contributed by [@Ufoex](https://github.com/Ufoex) in pull request #1; it uses libadrenotools and liblinkernsbypass by Billy Laws (BSD 2-Clause).

Everything else is as in 1.00. Installed copies of 1.00 find this update by themselves (or touch **Check for updates** in the main menu); the game files and settings stay.

If you try a driver and it helps or hurts, please say which phone and driver you used, and attach Log > Share.

Details: [README](https://github.com/DrTron1c/P.T.-Android-Port#readme) and [docs/android.md](https://github.com/DrTron1c/P.T.-Android-Port/blob/android/docs/android.md#custom-gpu-driver).
